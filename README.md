# Algoritmos Classificação de Dados - Exercícios em Java

Este repositório reúne **exercícios, práticas e projetos** desenvolvidos na disciplina de **Classificação de Dados**, utilizando a linguagem **Java**.  
O objetivo é registrar todos os conteúdos estudados, incluindo **POO, estruturas de dados, análise de algoritmos, ordenação e grafos**, organizados em código e exemplos comentados.

---

## 📚 Conteúdo da Disciplina

### 🔹 Programação Orientada a Objetos (POO) em Java
- Estrutura de aplicativos Java.
- Classes, objetos, construtores, atributos e métodos.
- Encapsulamento, modificadores de acesso, tipos primitivos e por referência.
- Princípios de orientação a objetos: **herança, polimorfismo, abstração e interfaces**.
- Pacotes, `enum`, sobrecarga e redefinição de métodos.
- **Classes genéricas** (parametrizadas), `ArrayList`, `LinkedList`.
- Tratamento de **exceções**.
- Modelagem em **UML**.

### 🔹 Exercícios Práticos de POO
- Sistema Cliente/Fatura/Itens.
- Jogo de dados (uso de `enum`, composição e `Random`).
- Hierarquia de mamíferos, itens seguráveis.
- Hierarquia de **Progressões** (Aritmética, Geométrica, Fibonacci) com uso polimórfico em **Fila genérica**.

### 🔹 Análise de Algoritmos
- Eficiência e crescimento de funções.
- **Notações assintóticas**: O, Ω e Θ.
- Complexidade de algoritmos.

### 🔹 Algoritmos de Ordenação
- **Clássicos:** Insertion Sort, Merge Sort, Bubble Sort, Selection Sort, Shell Sort.
- **Com estruturas auxiliares:** Heap e Fila de Prioridade → Heap Sort.
- **Divisão e Conquista:** Quick Sort.
- **Tempo Linear:** Counting Sort, Radix Sort, Bucket Sort.
- Comparação de desempenho (tempo/memória) das implementações.

### 🔹 Estruturas de Dados Avançadas
- **Listas, Pilhas e Filas** (implementações genéricas).
- **Árvores:** ABP, AVL, Heaps, Tries, Patricia Tries, Árvores B.
- **Grafos:**
  - Representações: lista e matriz de adjacência.
  - Algoritmos: BFS, DFS, Ordenamento Topológico.
  - Árvore Geradora Mínima: Kruskal, Prim.
  - Caminho Mínimo: Bellman-Ford, Dijkstra.
  - Todos os pares: Floyd–Warshall.
  - Fluxo Máximo: Ford–Fulkerson.
